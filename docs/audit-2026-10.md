## Bugs found and fixed

1. **Net Worth report picker missing in production.** `NetWorthTrendMonthPicker.jsx` was loaded with `vite_asset` but was never a rollup input. Dev mode hid it.
2. **One Plaid transaction could stop an account syncing.** A `personal_finance_category: null` (documented nullable) raised `AttributeError`. The task re-raises and saves the cursor only at the end, so every later sync failed on the same page.
3. **"Delete account" returned 500 for any user with a goal linked to an account.** `GoalAccountLink` `PROTECT`s `Account`. The hand-ordered delete list predated it and ran without a transaction, so the failure left the user half-deleted. It now uses `wipe_book` per book, inside one transaction.
4. **`purge_sample_transactions` crashed on every run.** It filtered by the dropped `BankTransaction.team` column. Removed, since it was an obsolete one-off cleanup.
5. **`api-client/` out of date.** Regenerated. Among the gaps, `SimpleAccountFromJSON` dropped `is_hidden`.

## Not changed: decisions for you

1. **"Ask Koala" (AI chat) is still the Pegasus demo.** The nav link is branded, but the page copy is Pegasus marketing. The default agent is a weather tool, and the only other agent is a superuser database/email tool. It has no access to budget data, and it pulls in `litellm`, `openai` and `pydantic-ai`. Either give it budget tools or remove it (`apps/chat`, `apps/ai`, `templates/chat`, `assets/javascript/chat`).
2. **`frontend/` SPA.** This is Pegasus's standalone React auth front end. It is commented out in `docker-compose.yml`, and `USE_HEADLESS_URLS` is off by default, so nothing deploys it. Only its Employees demo page was removed. Remove the rest unless a headless client is planned.
3. **Plaid Link is US-only** (`country_codes=["US"]` in `apps/plaid/services.py`), but the go-to-market plan is Canadian.
4. **Plaid pending→posted duplicates.** A categorized pending row survives `removed`, and the posted transaction arrives as a second, uncategorized row. A follow-up task with the details has been queued.
5. **Branding leftovers.** `PROJECT_METADATA["IMAGE"]` (the social-share image) is the Pegasus logo, the description says "for freelancers", and the footer reads "Built with SaaS Pegasus".
6. **`sync_all_plaid_items` is never scheduled.** Sync depends entirely on webhooks, and the webhook is unauthenticated. A missed webhook means no catch-up.
